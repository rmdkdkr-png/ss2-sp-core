Beetle NeoPop (SS2 One-button)

레트로아크 코어 설정 설명서 어디를 눌러야 뭐가 켜지는지, 항목 하나씩

이 코어는 삼스2에서만 동작합니다. 다른 네오지오 포켓 게임을 넣으면 원버튼 기능이 그냥 잠자코 있고 평범한 Beetle NeoPop 으로 돌아갑니다. 기존 코어를 대체해 두셔도 손해가 없습니다.

01코어 설치 — 세 가지 길

안드로이드 (가장 쉬움)

  1. 받은 .so 파일을 폰의 다운로드 폴더에 둡니다.
  2. 레트로아크 → Load Core (코어 불러오기)
  3. 맨 아래 Install or Restore a Core (코어 설치 또는 복원)
  4. 파일 목록에서 그 .so 를 고릅니다. 끝입니다.

요즘 폰은 ...android-arm64-v8a.so 를 쓰시면 됩니다. 아주 오래된 기기만 armeabi-v7a 입니다.

윈도우

RetroArch\cores\mednafen_ngp_libretro.dll RetroArch\info\mednafen_ngp_libretro.info

리눅스

~/.config/retroarch/cores/ ~/.var/app/org.libretro.RetroArch/config/retroarch/cores/ ← 플랫팩이면 이쪽
파일 이름을 바꿔야 할 수 있습니다. 받은 파일명(...linux-x86_64.so)은 어느 기기용인지 구분하려고 붙인 것입니다. 넣을 때는 mednafen_ngp_libretro.so (윈도우면 .dll)로 바꾸면 기존 코어를 대체합니다. 기존 것을 남기고 싶으시면 mednafen_ngp_ss2sp_libretro.so 처럼 다른 이름도 됩니다.

02롬이 목록에 안 보일 때

코어를 먼저 불러오면 레트로아크가 그 코어의 확장자만 걸러서 보여줍니다. 이 코어가 받는 건 .ngp .ngc .ngpc .npc 네 가지입니다.

먼저 이 토글부터 꺼 보세요.

설정(⚙) → 파일 브라우저 → 알 수 없는 확장자 필터 = 끔 Settings → File Browser → Filter Unknown Extensions = OFF

그러면 폴더 안 모든 파일이 보입니다. 그래도 비어 있으면 아래를 확인하세요.

확인내용
파일 이름확장자가 .bin 이거나 없으면 안 보입니다. samsho2.ngc 로 바꾸면 됩니다. .zip 이면 풀어서 넣어 보세요.
저장소 권한안드로이드 설정 → 애플리케이션 → RetroArch → 권한 → 모든 파일에 접근 허용. 폴더엔 들어가지는데 내용물만 안 보이면 이쪽입니다.
경로상위 폴더 로 한 칸 올라가 롬이 실제로 어디 있는지 보세요.

03코어 옵션 — 이 두 개만 보면 됩니다

롬을 실행한 다음, 화면을 열어 퀵 메뉴로 들어갑니다.

게임 실행 중 → 퀵 메뉴(Quick Menu) → 옵션(Core Options)

안드로이드에서는 화면의 레트로아크 메뉴 버튼(보통 좌하단 톱니 또는 뒤로가기)을 누르면 퀵 메뉴가 나옵니다.

항목값설명
SS2 One-button Specials Enabled 기본값. 이게 원버튼 기능 자체입니다. 끄면 순정 코어처럼 됩니다. 다른 게임 할 때 굳이 끌 필요는 없습니다 — 알아서 잠자코 있습니다.
SS2 One-button Layout Buttons / SP + direction 버튼을 어떻게 쓸지. 04에서 자세히 설명합니다.
Language japanese 원래 있던 항목입니다. 한글 패치본은 일본어로 두세요. 바꾸면 코어를 다시 불러와야 적용됩니다.
옵션이 안 보이면 코어가 제대로 안 바뀐 것입니다. 퀵 메뉴 위쪽이나 메인 화면 상단에 Beetle NeoPop (SS2 One-button) 이라고 적혀 있는지 확인하세요. 그냥 Beetle NeoPop 이면 순정 코어입니다.
설정은 게임별로 저장할 수 있습니다. 퀵 메뉴 → Overrides → Save Game Overrides. 삼스2에서만 이 설정이 뜨게 하고 싶을 때 쓰세요.

04버튼 배치 — 두 가지 방식

NGPC는 버튼이 A · B · Option 셋뿐입니다. 패드의 나머지가 통째로 놀고 있어서, 거기에 필살기를 답니다.

방식 ① Buttons — 필살기를 버튼에 직결 (기본값)

패드게임
B (아래쪽)A — 베기
A (오른쪽)B — 발차기
StartOption
X필살기 1번
Y필살기 2번
L필살기 3번
R필살기 4번
L2필살기 5번
R2필살기 6번

기술이 6개보다 적은 캐릭터는 남는 버튼이 아무 일도 하지 않습니다. 번호는 기술표 순서이고, 캐릭터·유파는 코어가 게임 메모리에서 자동으로 읽습니다. 캐릭터를 바꿔도 따로 설정할 게 없습니다.

방식 ② SP + direction — 브라우저 실행기와 같은 감각

X 하나로 다 씁니다. 십자키를 어느 쪽으로 누르고 있느냐로 갈립니다.

입력나가는 것
X 만중립 필살기
→ + X앞
← + X뒤
↓ + X아래
↓→ / ↓← + X대각 자리 (기술이 많은 캐릭터)
점프 중 X공중기

버튼이 적은 기기나, 실행기 쓰던 감각 그대로 가고 싶을 때 편합니다. 이 방식에서는 Y L R L2 R2 가 기술 1~5번으로 한 칸씩 밀립니다.

「앞 / 뒤」는 신경 쓰지 않으셔도 됩니다

캐릭터가 어느 쪽을 보고 있는지 코어가 게임 메모리에서 직접 읽어 커맨드를 좌우 반전합니다. 왼쪽에 있든 오른쪽에 있든 같은 버튼입니다.

버튼을 다른 데로 옮기고 싶으면

퀵 메뉴 → 컨트롤(Controls) → Port 1 Controls

여기서 SP 1 ~ SP 6 이라는 이름으로 보입니다. 원하는 물리 버튼에 다시 매핑하세요. 화면 터치 버튼 위치는 설정 → 온스크린 디스플레이 → 온스크린 오버레이 에서 조절합니다.

05강하게 내려면 — 길게 누릅니다

이번 판에서 새로 넣었습니다. 이전 코어는 항상 약으로만 나갔습니다 (실기 제보로 확인). 지금은 필살기 버튼을 잡고 있는 만큼 게임에 버튼이 계속 들어갑니다.
누르는 법게임에 들어가는 버튼 유지판정
톡 친다 (1~3프레임)6프레임약
조금 잡는다 (8프레임)8프레임약
지그시 잡는다 (15프레임)15프레임강
계속 잡고 있는다26프레임에서 자동으로 끊음강

기준은 9프레임(약 0.15초) 입니다. 그 이상 잡으면 강입니다. 끝없이 잡고 있어도 26프레임에서 알아서 놓아 줍니다 — 안 그러면 다음 입력이 막힙니다.

일반 공격(A·B)의 강약은 원래대로 동작합니다. 코어가 손대지 않고 그대로 흘려보내므로 실기와 완전히 같습니다. 이 항목은 필살기 버튼에만 해당됩니다.
기술이 나가는 중에는 다른 입력이 무시됩니다. 코어가 커맨드를 프레임 단위로 밀어 넣는 동안 십자키·버튼을 눌러도 반영되지 않습니다. 커맨드가 섞이면 기술이 어긋나기 때문입니다. 길어야 0.3초 정도입니다.

06잘 안 될 때

증상확인할 것
필살기가 아예 안 나감 ① 전투 중인가요? 메뉴·데모에서는 동작하지 않습니다.
② 옵션의 SS2 One-button Specials = Enabled
③ 상단에 (SS2 One-button) 이 붙은 코어가 맞나요?
④ 롬이 한글 패치본인가요? 기술표가 그 기준으로 만들어져 있습니다.
맞고 있을 때 안 나감 피격 경직 동안은 게임이 방향 입력을 받지 않습니다. 게임 쪽 사양이고 실기와 같습니다. 코어는 경직이 풀릴 때까지 기다렸다가 넣습니다.
점프 중에 지상기가 안 나감 일부러 그렇게 했습니다. 공중에서 지상기를 쏘면 씹히므로 착지까지 기다렸다가 냅니다(최대 1.5초).
강이 안 나옴 0.15초 이상 잡아 보세요. 그리고 이 기능이 들어간 최신 코어인지 확인하세요.
다른 기술이 나옴 게임의 커맨드 판정이 관대해서 짧은 커맨드가 긴 커맨드를 가로챌 수 있습니다. 코어가 램에 1바이트를 써서 입력 기록을 정리하는 방식으로 대부분 막았지만 (실측 0/42 → 41/42) 완전하지는 않습니다.
세이브 후 이상해짐 스테이트를 불러오면 코어가 진행 중이던 커맨드를 자동으로 버립니다. 그래도 이상하면 코어 리셋 한 번 해 보세요.

07알아 두면 좋은 것

  • 이 코어는 게임을 고치지 않습니다. 없는 기술을 만들거나 데이터를 바꾸지 않고, 커맨드를 대신 눌러 줄 뿐입니다. 경직·공중 판정 같은 원작 규칙은 그대로 지킵니다.
  • 캐릭터·유파(수라/나찰)는 자동 인식입니다. 전투가 시작되면 알아서 그 캐릭터 기술표로 바뀝니다.
  • 카드가 필요한 기술은 전투 전 '능력 추가' 에서 지정해 두어야 나갑니다.
  • 세이브 스테이트, 되감기, 치트 등 레트로아크 기능은 전부 평소대로 씁니다.
