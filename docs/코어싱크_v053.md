## 코어에 없는 것 (제한)

| 없는 것 | 왜 |
|---|---|
| **화면 양옆 아트웍 · 일러스트** | 브라우저는 캔버스 밖 여백을 HTML로 채웁니다. 코어는 자기 프레임버퍼 밖을 못 그립니다. **가능은 합니다** — 화면 가로를 늘려(160 → 256) 양옆에 직접 그리면 됩니다. 다만 화면비가 또 바뀌고, 일러스트도 코어가 선택 화면에서 직접 잘라 캐시해야 합니다. 원하시면 옵션(기본 끔)으로 넣겠습니다. |
| **시작 화면 (SP로 시작·레트로 테마)** | 코어에는 런처가 없습니다. 롬을 여는 것은 레트로아크 몫입니다. |
| **기술 배치 편집** | 엔진에 API는 있지만 코어 옵션으로 30유파×7자리 편집기를 만들 수 없습니다. 기본 배치로 돕니다(앱·실행기에서는 편집 가능). |
| **설정 항목 수** | 코어 옵션 5개(원버튼 켬·해설 켬·화자·표시 자리)뿐입니다. 패드/버튼 크기·투명도·배치는 레트로아크 오버레이 설정 쪽입니다. |
| **카드 판정 정밀도** | 실행기는 어느 카드인지(`ci`)까지 보고, 코어는 "필살기 카드(2·3)가 꽂혔나"까지만 봅니다. 코어 기술표에 카드 번호가 없어서입니다. |
| **진단 표시(지연 계측)** | 브라우저 전용 진단입니다. |

## 일부러 안 맞춘 것 — 입력 속도

실행기는 **최속 고정**(방향 2f · 버튼 3f)으로 바꿨지만, 코어는 **방향 3f · 버튼 6f** 를 유지했습니다.
같은 코어에 실측해 보니 **더 빠른 쪽이 오히려 덜 나갑니다.**

| 타이밍 | 발동 성공 |
|---|---|
| 코어 현행 (3f / 6f) | **126/144 (88%)** |
| 실행기 최속과 동일 (2f / 3f) | 121/144 (84%) |

캐릭터별로는 갈포드가 12/24 → 7/24 로 확연히 나빠졌습니다(6개 세이브스테이트 × 4방향 × 6회).
그래서 코어는 그대로 뒀습니다. 실험해 보시려면 환경변수 `SS2SP_STEP` · `SS2SP_HOLD` 로 바꿀 수 있습니다.

> 참고: 같은 이유로 **실행기 쪽 최속 고정도 다시 재 볼 값어치가 있습니다.**
> 브라우저는 입력 경로가 달라 그대로 옮겨 볼 순 없지만, 원하시면 실행기에서도 같은 방식으로 실측해 보겠습니다.
