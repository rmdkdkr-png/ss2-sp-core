패드게임에서

NGPC 는 버튼이 A·B·옵션 셋뿐입니다. 레트로아크 패드의 B 가 게임의 A(베기), A 가 B(발차기) 입니다 — 뒤집혀 있으니 주의하세요.

오버레이 그림

그림을 길게 눌러(PC 는 오른클릭) ngpc.png 로 저장하세요. 아래 설정 파일과 같은 폴더(다운로드 폴더면 됩니다)에 둡니다.

설정 파일


        

          overlays 폴더에 안 넣어도 됩니다. 오버레이 경로는 그냥 파일 경로라
          읽을 수 있는 자리면 어디든 됩니다. 요즘 안드로이드는 앱 폴더에 손을 못 대니
          다운로드 폴더를 쓰세요.
        

        

          1. ngpc.cfg 와 ngpc.png 를 둘 다 다운로드 폴더에
          저장합니다 (같은 폴더여야 그림을 찾습니다).

          2. 레트로아크 → 설정 → 화면 표시 → 온스크린 오버레이 → 오버레이 지정

          3. 파일 고르는 창에서 다운로드 로 찾아가 ngpc.cfg 를 고릅니다.
        

        

          목록에 다운로드 폴더가 안 보이면 설정 → 디렉토리 → 오버레이 를
          다운로드 폴더로 바꿔 두면 다음부터 거기서 열립니다.
