# 월화 기술 커맨드 — 공략집 값과 실측

**출처**: GameFAQs, *The Last Blade: Beyond the Destiny — Move List and Guide*, L.S.D, v1.2 (2000-09-26).
<https://gamefaqs.gamespot.com/ngpc/197757-the-last-blade-beyond-the-destiny/faqs/7813>

⚠ **이건 가설이지 증명이 아니다.** 그 글쓴이는 「나는 일본판을 갖고 있다」고 적어 뒀고
우리 대조군은 **UE 판**이다. 기술 «이름»은 그쪽 번역이고, 우리가 검산한 것은 «커맨드»뿐이다.
표는 이름일 뿐 검산이 아니다 — 슬롯에 넣기 전에 캐릭터마다 다시 눌러 봐라.

## 규격 (공략집)

| 것 | 값 |
|---|---|
| 버튼 | **A = 베기(SLASH) · B = 발차기(KICK)** |
| 방어 | F+B = 상단 패링 · DF+B = 하단 패링 |
| 잡기 | 뒤+B (근접) |
| 세기 | 뒤+A 약 · A 중 · **길게 A 강** · 앞+A 최강 |
| 달리기 | 앞,앞 · 뒤로 뛰기 = 뒤,뒤 |
| **속성** | **POWER(力) / SPEED(技)** — Ability Select 가 이것이다 |

**★ 속성이 «보통 필살기»는 안 건드린다.** 캐릭터별 기술표가 모드별로 갈려 있지 않다.
갈리는 것은 초필뿐이다 —

- **ES** (Enigma Slash) : 두 모드 공통, 게이지 가득
- **HT** (Hidden Thrust) : **POWER 전용**
- **EF** (Enigma Frenzy) : **SPEED 전용**
- 막을 수 없는 기술 = 앞,앞+B (POWER 전용) / 중단 = 앞,앞+B (SPEED 전용)
- 반격기 = 가드 중 B,DB,D + A+B (게이지 50% 이상, POWER 전용)

→ **슬롯 여섯(N/F/B/D/DF/DB)은 캐릭터당 한 벌이면 된다.** 초필 자리만 속성을 봐야 한다.
  기획서의 위험 항목 「추가 능력이 기술표를 흔든다」는 **이 범위로 좁혀졌다.**

## 실측 — 카에데 (순정 UE, 트레이닝 무대, 위상 2종)

동작 ID `0x0370` 로 갈랐다. **위상 0·1 이 전부 같은 값**이다.

| 넣은 것 | act | 공략집이 적은 것 |
|---|---|---|
| A | **96** | 서서 베기 |
| B | **128** | 킥 |
| 236+A | **112** | Single Slash Squall |
| 623+A | **116** | Single Slash Wind Fang |
| 214+A | **148** | Single Slash Fillet Flash |
| 214+B | **168** | East Wind Wallop |
| 41236+B | 148 | Storm Blast (근접) — **떨어져 있어 헛나갔다. 148 이 214+A 와 겹친다** |
| **421+A** | **96** | **표에 없는 커맨드 — 평타만 나왔다** |

**대조군이 섰다**: 표에 있는 커맨드는 기본기와 다른 값을 내고, **표에 없는 421+A 는 평타(96)**다.
즉 공략집의 커맨드가 실제로 이 롬에서 먹는다.

⚠ **148 이 둘에 겹친다.** M3 의 관문에 「슬롯끼리 지문이 겹치면 경고」가 있는 이유가 이것이다.
근접 기술은 **붙여 놓고** 다시 재야 한다.

기타 act 값: 4 서있기 · 12 웅크림 · 20 앞걷기 · 24 뒤걷기.

### 숨은 캐릭터
카에데(각성) · 사나다 코지로 · 타카네 히비키 · 세츠나 · 카가미 시노스케 · 코류.
두루마리로 열린다(공략집 Scroll 절). **로스터는 프로필 기준 14명**이고 카에데(각성)까지 세면 더 는다.
숨은 캐릭터 커맨드는 필요할 때 다시 뽑는다 — 지금 슬롯 작업에 안 쓴다.

## 이 표에서 슬롯에 쓸 만한 것

**거의 모든 캐릭터가 236·214·623 을 갖는다.** SvC·KOF 와 같은 뼈대다.
다만 월화만의 것이 둘 있다 —

1. **모으기 캐릭터가 있다** (와시즈카 뒤모아앞·아래모아위, 리 아래모아위).
   SvC 에서 「모으기 기억」으로 푼 문제가 여기도 그대로 있다.
2. **파생이 많다** (아카리의 623 뒤 여덟 갈래, 리의 A+B 뒤 다섯 갈래).
   MECH.md §5 가 「파생을 반드시 파라 — 없으면 «기술 콤보가 안 나간다»가 된다」고 적어 둔 그것이다.
