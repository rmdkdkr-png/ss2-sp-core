## 트레이닝 무대로 가는 길 (실측)

```
자연 부팅 4500프레임 → 제목 「PRESS A BUTTON」
  A → 1P PLAY 메뉴
  A → 모드 선택 (STORY / SURVIVAL / TIME ATTACK / TRAINING)
  ↓ ×3 → TRAINING
  A → Player Select   ← lb_psel.st 를 여기서 뜬다
  A → (P1 확정)
  A → **Ability Select**
  A → (P2 캐릭)
  A → (P2 확정)
  → 무대                ← lb_train.st
```

- **버튼 문자는 레트로패드 기준**이다: NGP A = 대본 `B` · NGP B = 대본 `A`.
- **트레이닝 모드가 있다는 것이 이번 이식의 제일 큰 이득이다.** SvC 는 스파링 무대를 억지로
  구웠고 애니 뱅크가 안 갱신돼 자동 실측에 못 썼다. 월화는 게임이 허수아비를 준다.
- 게임이 화면에 **「DAMAGE %」와 히트 수**를 띄운다 — 교차 증인으로 쓸 수 있다.
- ⚠ **Ability Select 가 흐름 안에 있다**(POWER 표기 확인). 속성·장비가 기술표를 흔드는지는
  **미측정**이다. 슬롯을 짜기 전에 반드시 가른다.
- ⚠ Player Select 에서 **다섯 번** 눌러야 무대다. 두 번만 누르고 「무대」라 이름 붙였다가
  Ability Select 를 찍었다. **화면을 한 칸씩 찍어 확인해라.**

## ★ 방향이력 링 — 찾았다

```
링    0x1313 + (n & 0x7F)     n = 0…127   (128칸, 1바이트 간격)
머리  0x1312                  다음에 쓸 칸의 색인
한 칸 2프레임                  → 256프레임을 기억한다
값    NGP 패드 비트 그대로      U=1 D=2 L=4 R=8 · NGP A=16 · NGP B=32
P2    +0x88 (머리 0x139A, 링 0x139B~0x141A)
```

**SvC·KOF 와 구조가 다르다.** 그 둘은 값이 **밀린다**(간격 2). 월화는 **값이 안 움직이고
머리만 나아간다**(간격 1). 결과는 같지만 주입 코드가 다르다 — 밀기를 흉내 내면 안 된다.

근거:
- 앞을 4프레임 잡으면 f2 에 0x135B, f4 에 0x135C 에 `8` 이 앉는다 — **2프레임에 한 칸**.
- 앞4 → 중립10 → 뒤4 를 넣으면 `4` 가 0x135D 가 아니라 **0x1362** 에 앉는다.
  사이 다섯 칸이 0 으로 남는다 → **중립도 기록된다.** 칸 수가 프레임 수와 정확히 맞는다.
- R·L·D·U 넷 다 「머리 72 → 0x1313+72 = 0x135B 에 값이 앉고 머리가 73 이 된다」.
- 한 방향을 600프레임 잡으면 `0x1313~0x1392` 128칸이 전부 그 값이 된다 — 그 이상 안 번진다.
- 머리를 중립으로 굴리면 124 → 16 으로 돌아온다(40프레임=20칸, 124+20−128=16) → **128에서 되돌아온다.**

⚠ **한 칸만 poke 로 붙잡아 증명하려 하지 마라.** KOF 에서 링을 정적으로 붙잡았더니 게임이
읽는 시작점이 돌아 사실상 모든 회전을 시도하게 돼 증명이 안 됐다. **한 번만 쓰는 것**이 본질이다.

## 램 후보 (아직 확정 아님)

| 주소 | 무엇으로 보이나 | 쉴 때 | 근거 |
|---|---|---|---|
| **0x0370** | **동작 ID(act)** | **4** | 서서 베기 96 · **앉아 베기 120** · 점프 12→44→48. 구간마다 한 값으로 계단처럼 간다 |
| 0x037C | 공격 판정 구간? | **255** | 기술이 나가는 동안만 255 를 벗어난다(서서A 52→32, 앉아A 80→28) |
| 0x0F60/61 | **애니 대본 커서(16비트)** | 0x4FC6 | 서서A 0x56FD · 앉아A 0x3B5B. SvC 0x0958·KOF 0x0D78 에 해당 |
| 0x0F5B · 0x0F64 | 애니 번호 | 78 | 둘이 늘 같이 움직인다 |
| 0x036A · 0x03EA | 가로 위치? | 120 | 앞 201 · 뒤 56. **둘이 값이 같다** — 하나는 사본이거나 카메라다 |

**승격 조건을 아직 못 채웠다.** 규칙은 「독립 시나리오 2개 + 위상 2종 + 교차 증인」인데
**위상 2종을 안 돌렸다.** 그 전에는 코드에 값을 박지 마라.

**아직 못 찾은 것**: 콤보 카운터 · 상대 체력 · **좌우 반전** · 캐릭터 id.
⚠ 반전은 특히 조심해라 — KOF 는 `0x0D4A` 를 반전으로 잘못 잡았는데 그건 「필살기를 한 번
쓰면 서고 안 내려오는 플래그」였고, 배포된 엔진이 **한 라운드 두 번째 발동부터 커맨드를
좌우로 뒤집었다.** 관문 40/40·98/98 이 전부 초록이었던 이유는 **시행마다 세이브를 다시
불러왔기 때문**이다.

## 함정 (이번에 밟은 것)

1. **`!w` 의 오프셋 목록은 159자에서 잘린다**(`ngprun.c` 의 `%159s`). 30칸이 한계다.
   64칸을 주고 24칸만 받아 「링이 없다」로 읽을 뻔했다.
2. **`!w` CSV 열은 `frame,pad,<오프셋…>`** 이다. `pad` 를 첫 오프셋으로 읽으면 전부 한 칸 밀린다.
3. **`30 D` 뒤에 `4 B` 는 앉아 베기가 아니다** — 방향을 떼고 친 것이다. `12 D B` 로 같이 잡아라.
4. **잡음 바이트 0개**다. SvC(9)·SS2(3)와 달리 이 무대는 결정적이라 두 번 뜨기가 싸다.
   그래도 **거르는 절차는 남겨 둔다** — 무대가 바뀌면 다시 생긴다.
