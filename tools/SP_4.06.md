# SP 코어 4.06 — 월화·KOF R-2 초필과 파생기

PocketCore의 코어만 업데이트하면 됩니다. APK 재설치는 필요 없습니다.

## 조작

| 게임 | 조작 | 동작 |
|---|---|---|
| 월화 | SP+A | 초필살기 |
| 월화 | SP+B | 잠재오의 |
| 월화 | SP+A+B | SPEED 모드 난무오의 시동 |
| KOF R-2 | SP+펀치 / SP+킥 / SP+펀치+킥 | 캐릭터별 1·2·3번 초필 커맨드 |
| 공통 | 대응 기술 도중 SP | 파생 입력; 방향으로 분기 선택 |

월화의 기존 방향+SP 일반기는 유지했습니다. SP를 길게 누르면 버튼 유지가 늘어나며, 짧게 누르면 기존처럼 입력합니다. R-2의 앞아래+SP도 캐릭터별 첫 초필을 입력합니다.

게이지·체력·검질·거리·공중 여부와 연결 타이밍은 원래 게임의 조건을 따릅니다. 난무오의는 시동만 지원하며 전체 연속기를 자동으로 넣지는 않습니다. R-2에서 초필이 두 개인 캐릭터에 세 번째 기술을 만들어 넣지 않습니다.

월화: 각성 카에데는 앞+SP+A/B로 다른 초필/잠재오의를 선택합니다. 코류는 앞·아래+SP+A로 다른 초필을 선택하고, 카가미·코류의 공중 기술도 지원합니다.

## 확인한 파생 입력

월화: 카에데 추가타, 아카리 잡기·구르기 분기, 와시즈카 연계·반복, 코지로 추가타, 리의 연계·자세 분기, 잔테츠 공중 추가타, 카가미 추가타, 히비키 이동 분기, 세츠나 추가 커맨드, 코류 추가타를 검사했습니다. 방향 분기는 뒤/아래/앞으로 선택합니다. 모든 자세의 모든 분기를 자동화했다고 보장하지 않습니다.

R-2: 쿄의 약·강 황물기 계열과 공중 추가타, 료 추가타, 레오나 강 세이버 후속, 야시로·셸미 추가타, 아테나 초필 종료 입력, 이오리·사이슈 연속기를 검사했습니다. 일반 선택 14명 대상이며 숨겨진 대체 스타일은 이번 전수 검사의 대상이 아닙니다.

## 검증

Windows libretro 실제 게임 실행에서 수동 커맨드와 SP의 동작 기록을 비교했습니다.

- 월화 초필/잠재오의/난무 시동 등 51개 입력 경로 × 좌우 × 입력 위상: 204/204.
- 월화 파생 23개 경로 × 좌우 × 입력 위상: 92/92.
- 월화 일반 SP 반복: 1,580/1,580; 캐릭터별 5회 연속: 75/75.
- R-2 초필 32개 입력 경로 × 좌우 × 입력 위상: 128/128; 14명 × 5회 연속: 70/70.
- R-2 파생 11개 경로 × 좌우 × 입력 위상: 44/44.
- 사쇼2 v1.01, SvC, R-2, 메탈슬러그 1·2, 아랑전설의 제한된 공통 입력 검사에서 화면과 안정 RAM 차이 없음. SvC 음성은 기준 코어 자체가 반복 실행 간 달라 비교 판정에서 제외.
- Android 3개 ABI는 빌드와 파일 형식을 확인합니다. Android 실기 플레이 검수는 아직 하지 않았습니다.

입력 이력과 패드 입력을 처리하며 ROM·저장 플래시·체력·게이지·기술 상태를 강제로 바꾸지 않습니다. 검사 중 월화 숨김 캐릭터는 선택 화면에서만 선택 값을 설정했습니다. 배포물에 ROM이나 세이브 상태는 없습니다.

## 설치 / 되돌리기

PocketCore 코어 업데이트에서 4.06을 받습니다. 직접 넣은 PocketCore/cores/svc*.so가 있으면 그 파일이 우선하므로 해당 ABI의 파일도 교체해야 합니다. 문제 발생 시 같은 릴리즈에 남긴 4.05로 되돌릴 수 있습니다.
