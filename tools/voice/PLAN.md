# 음성 해설(더빙) + 커스텀 믹싱 기획 — v0

> 목표: SS2 해설 전 대사를 ElevenLabs 음성으로 생성해, 코어가 이벤트 시점에
> 게임 소리 위에 직접 믹싱한다. 롬은 건드리지 않는다(시퀀스 음악이라 교체 불가,
> 코어 믹싱이 음질·용량·법적 리스크 전부 우위).

## 0. 실측 물량 (2026-08-28 기준 HEAD)

| 항목 | 수치 |
|---|---|
| 해설 대사(lines.h 유니크) | **4,235줄 / 61,277자** (평균 14.5자) |
| 그중 자리표(%s이름·%d숫자) 포함 | **1,214줄** |
| 정적(그대로 녹음 가능) | **~3,021줄 / ~44,000자** |

| 화자 | 15캐릭터 + 심판 = **16보이스** |

## 1. 생성 파이프라인 (PC, tools/voice/)

```
extract_lines.py   lines.h 파싱 → lines.tsv (id=FNV1a해시, 화자, 텍스트, 종류)
                   ├ 대사 배열만 추출(UI/메뉴 문자열 제외)
                   └ 발음 치환표 적용(고유명사·사극체 교정)
synth.py           ElevenLabs API 일괄 생성 (증분: 해시 없는 것만 → 대사 수정시 재생성 최소)
master.py          ffmpeg: 무음 트림 → loudnorm(I=-16) → 44.1kHz mono → OGG q1
                   → voicepack/<해시>.ogg + manifest.tsv
qc.py              총 재생시간·클리핑·누락 리포트 + 랜덤 시청 샘플
```

- **비용**: 61k자 전량 = Multilingual v2 기준 ~61k 크레딧, Flash v2.5는 절반.
  → **Creator 플랜($22/월, 100k) 한 달이면 전량 + 재생성 여유.** 유저 API 키 필요.
- **용량**: 3,000클립 × 평균 2.5초 × OGG ~10KB/초 ≈ **25~35MB 팩** (폰 무리 없음)
- **보이스 캐스팅**: Voice Design으로 캐릭터당 시안 2~3개 생성 → **유저 시청회로 확정**
  (실존 성우 복제 금지 — 오리지널 AI 보이스만. 생성물은 우리 저작물 → 릴리스 동봉 가능)

## 2. 자리표 대사 전략 (1,214줄)

| 단계 | 방법 | 커버리지 |
|---|---|---|
| 1차 | 정적 3,021줄만 음성, 자리표 대사는 텍스트 유지 | 71% |
| 2차 | %s(이름) 대사: 이름 17종(로스터15+간다라+상대) 조합 사전 생성 — 빈도 상위부터 | +대부분 |
| 3차 | %d(숫자) 대사: 숫자 없는 문장으로 **리라이트** ("7명 베고" → "몇을 벤 거냐…") | 100% |

숫자 스플라이싱(조각 잇기)은 억양이 부자연스러워 채택 안 함.

## 3. 코어 믹싱 엔진 (ss2voice.c 신설)

- **후킹**: emit()/ref_shout() 한 지점 — 텍스트(자막)와 동시에 `voice_say(해시)`
- **채널**: 해설 1채널(순차 큐, 기존 2칸 큐 재사용) + 심판 우선채널(해설 컷/덕)
- **믹싱**: retro_run에서 sound_buf에 가산. `출력 = 게임×(덕킹시 0.4) + 음성×볼륨`, ±3dB 헤드룸 클램프
- **디코드**: stb_vorbis(퍼블릭도메인 단일헤더). 팩이 이미 44.1k mono라 리샘플 없음
- **로딩**: RetroArch system_dir/ngpvoice/ (팩 폴더만 갈아끼우면 교체). 없으면 완전 무해(현행과 동일)
- **옵션**(오버레이+코어옵션): 음성 켬/끔 · 볼륨 3단 · 덕킹 켬/끔
- **앱(NGP.emu) 이식**: 코어에서 검증 후 동일 모듈 이식

## 4. BGM 교체 (후속 단계)

- 스테이지/모드 감지는 RAM으로 이미 가능 → 스테이지별 곡 루프 재생
- 원곡 소거는 불완전(효과음과 PSG 채널 공유) → **1차: PSG 감쇠 옵션 + 우리 곡 오버레이**
- 곡 소스: 유저 제공 파일 또는 AI 생성(Suno 등) — 팩 폴더에 stage00.ogg… 규약
