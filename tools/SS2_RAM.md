# SS2 전투 램 — 효과음에 쓸 자리

소리를 붙이려면 「언제」를 알아야 한다. 여기 적힌 것은 전부 실측이다.

## 액션 ID

P1 `0x0E3E` · P2 `0x0E7E` (둘 다 16비트, 리틀엔디언).

| 값 | 정체 | 근거 |
|---|---|---|
| `0x38` (56) | **가드** | 뒤를 잡을 때만 나오고 75프레임 동안 깎인 체력 **1**. 계속 켜지는 게 아니라 뭉텅이로 나타난다 — 자세가 아니라 **막은 순간**이다 |
| `0xD8` (216) | 피격 | 36프레임 동안 22 깎임 |
| `0xE8` (232) | 피격(큰 것) | 13프레임 동안 17 깎임 |
| `0x20` (32) | 뒤로 걷기 | 170프레임 동안 0 깎임 |
| `<0x50` | 행동 가능 | 기존 메모 |
| `0x60~0x6F` | 강베기 | 기존 메모 |
| `0x13C~0x154` | 다운 | 기존 메모 |
| `0x180+` | 필살기 | 기존 메모 |

**주의**: `OFF_BLK1 0x1B51` / `OFF_BLK2 0x1D51` 은 이름과 달리 **가드가 아니라 캐릭터 번호**다.
(ss2comm.c 주석: 「보스전에서 BLK2 는 잔존값이라 겐주로(0x30)·아수라(0x88)로」)
이름만 보고 가드로 쓰면 안 된다.

## 체력

P1 `0x1A46` · P2 `0x1C46` (8비트). 감소량이 곧 타격 세기다.
기둥 흔들림(`st_shk`)이 쓰는 경계 `>=12` / `>=4` 를 소리도 그대로 쓴다 —
화면이 크게 흔들리는데 소리가 약하면 어색하다.

## 재는 법

전투 세이브: `~/ss2/saves/ss2/ss2_fight.st` (1P 수라 vs COM 수라, 실전 중)
없으면 메뉴부터 뚫어야 한다 — 부팅 500프레임 → B(메뉴) → B(1인 대전) → B×5 → 전투.

관측: `svcrun` 의 `!ws <태그>` 가 SS2 오프셋을 찍는다(`SS2_CSV` 로 경로 지정).
`!w` 는 SvC 오프셋이라 SS2 에 쓰면 엉뚱한 값이 나온다.

가드를 재는 요령 — **붙어서** 재야 한다. 멀리서 뒤로 걸으면 공격이 그냥 빗나가는데
그것을 「막았다」로 오인한다(실제로 첫 측정에서 그랬다). 앞으로 걸어 붙인 뒤 뒤를 잡는다.
대조군은 같은 자리에서 아무것도 안 하기 — 피해가 65 → 47 로 줄면 진짜 막고 있는 것이다.

## 아직 못 찾은 것

- 칼 휘두르는 순간(헛침) — 공격 동작 진입 에지는 잡히지만 「베는 프레임」은 따로 없다
- 무기 날리기 / 무기 떨구기
- 튕김(가드 성공 후 밀림)이 `0xE8~0xF0` 인지 — 이 값들은 피해도 같이 나서 애매하다
